Title: projections_from_fundamental doesn't support batching properly
Date: 2021-05-03T08:39:12+00:00
URL: https://github.com/kornia/kornia/issues/996

Description:
## 🐛 Bug

The [docs](https://kornia.readthedocs.io/en/v0.5.0/geometry.epipolar.html#kornia.geometry.epipolar.projections_from_fundamental) state that the shape of input `F` is `(*, 3, 3)`, but in practice only `(b, 3, 3)` seems to be supported with both `(3, 3)` and `(a, b, 3, 3)` failing.

## To Reproduce
```python
import torch
import kornia

F = torch.randn(1, 3, 3)
print(kornia.projections_from_fundamental(F).shape)

F = torch.randn(1, 1, 3, 3) # fails
print(kornia.projections_from_fundamental(F).shape)

F = torch.randn(3, 3) # fails
print(kornia.projections_from_fundamental(F).shape)
```
