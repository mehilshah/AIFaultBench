Description:
### 🐛 Bug

There seems to be a bug when using the the Gymnasium ClipAction wrapper.
The function make_vec_env changes the action space to [-Int, Inf].

The problem is in make_vec_env at `env = wrapper_class(env, **wrapper_kwargs)`.

### To Reproduce

```python
from stable_baselines3.common.env_util import make_vec_env                                                                           
import gymnasium as gym                                                                                                                 
                                                                                                                                     
wrapper_class = gym.wrappers.ClipAction                                                                                              
env = make_vec_env("LunarLander-v3",                                                                                                 
                   n_envs=1,                                                                                                         
                   env_kwargs={"continuous": True},                                                                                  
                   wrapper_class=wrapper_class)                                                                                      
print(env.action_space)
```


### Relevant log output / Error message

```shell
Box(-inf, inf, (2,), float32)
```
