### Problem description

When using ChatAgent.step() for streaming output in stream mode, the program will report an error in handling the token usage logic. The reason seems to be that the usage_dict["completion_tokens"] for some stream chunks is None, but the code still attempts to execute int += None, resulting in a TypeError.

### Reproducible example code

The Python snippets:

```python
from camel.agents import ChatAgent
from camel.models import ModelFactory
from camel.types import ModelPlatformType, ModelType
 
# 1. 创建支持流式输出的模型
streaming_model = ModelFactory.create(
    model_platform=ModelPlatformType.DEFAULT,
    model_type=ModelType.GPT_4O_MINI,
    model_config_dict={"stream": True}  # 启用流式模式
)
 
# 2. 初始化流式对话代理
agent = ChatAgent(
    system_message="你是一个简洁的助手，用要点回答问题",
    model=streaming_model
)
 
# 3. 获取流式响应并实时打印
for chunk in agent.step("介绍CAMEL框架的核心功能"):
    print(chunk.msg.content, end="", flush=True)  # 实时输出每个块
```
