# recovered-from-issue: https://github.com/SWE-agent/SWE-agent/issues/1078

TITLE
Open PR tool creates a token limit exceeded for PR body issue

BODY
### Describe the bug

I have set up SWE Agent as part of GH Actions to run when a user opens a new issue. This bug is sporadic because it depends on the task. It completes the entire fixing process up until the PR needs to be opened. Then it fails saying that the PR body limit has been exceeded. Ideally I would suggest an option to automatically truncate or summarize the PR body in some way to prevent this from happening. 

Note: working_config in the file below is the same default config file provided in sweagent repo

### Steps/commands/code to Reproduce

```
name: SWE-agent Autofix

on:
  issues:
    types: [opened, reopened, edited]
 
jobs:
  autofix:
    runs-on: ubuntu-latest
    permissions:
      contents: write
      issues: read
      pull-requests: write
    
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v3
        with:
          path: repo

      - name: Set up Python 3.11
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install Dependencies
        run: |
          pip install --upgrade pip
          
      - name: Install SWE-agent from Source
        run: |
          # Clone and install SWE-agent from source
          git clone https://github.com/SWE-agent/SWE-agent.git
          cd SWE-agent
          python -m pip install --upgrade pip && pip install --editable .
          cd ..
          # Install linting tools
          pip install pylint flake8

      - name: Test Docker
        run: docker run hello-world

      - name: Update Config with Dynamic Values
        run: |
          # Create a copy of the stored config file and move it to SWE-Agent directory
          cp repo/scripts/config/sweagent_pr_generator.yaml SWE-agent/working_config.yaml
          
          # Update variables in the config
          sed -i "s|{{GITHUB_REPOSITORY}}|${{ github.repository }}|g" SWE-agent/working_config.yaml
          sed -i "s|{{ISSUE_NUMBER}}|${{ github.event.issue.number }}|g" SWE-agent/working_config.yaml
          
          # Display the updated config for debugging
          cat SWE-agent/working_config.yaml

      - name: Run SWE-agent on the Issue
        working-directory: ./SWE-agent
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GITHUB_TOKEN: ${{ secrets.PAT_TOKEN }}
        run: |
          # Run sweagent from the SWE-Agent root directory
          sweagent run \
            --config working_config.yaml \
            --agent.model.name=claude-3-7-sonnet-20250219 \
            --agent.model.per_instance_cost_limit=2.00 \
            --agent.model.max_output_tokens=32000 \
            --env.repo.github_url=https://github.com/${{ github.repository }} \
            --problem_statement.github_url=https://github.com/${{ github.repository }}/issues/${{ github.event.issue.number }} \
            --actions.open_pr=True

      - name: Add Comment to Issue
        uses: peter-evans/create-or-update-comment@v2
        with:
          token: ${{ secrets.PAT_TOKEN }}
          issue-number: ${{ github.event.issue.number }}
          body: |
            I've initiated an automated fix for this issue using SWE-agent.
            
            A pull request should be created shortly if a solution is found. Please review the changes when the PR appears.
```
