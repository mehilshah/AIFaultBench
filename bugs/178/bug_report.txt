Title: Inline regex flags like `(?s)` crash Lark lexer
Date: 2025-12-01T02:53:39+00:00
URL: https://github.com/lark-parser/lark/issues/1569

Description:
**Describe the bug**

Using an inline flag at the start of a token regex (e.g., `/(?s)./`) is valid in Python’s `re`, but Lark wraps terminals inside grouping constructs before compilation. 

**To Reproduce**
```python
from lark import Lark

grammar = r"""
start: char+
char: /(?s)./
"""

parser = Lark(grammar, lexer="basic")
list(parser.lex("\n"))
```
