TITLE
[BUG] SumSegmentTreeFp32 not available

BODY
## Describe the bug

When instantiating  a PrioritizedSampler, I get an `RuntimeError: SumSegmentTreeFp32 is not available.` in `torchrl/data/replay_buffers/samplers.py", line 462, in _init`.

## To Reproduce

```python
from torchrl.data import TensorDictReplayBuffer, LazyTensorStorage, PrioritizedSampler
device = torch.device("cuda:0")

rb = TensorDictReplayBuffer(
        storage=LazyTensorStorage(max_size=100, device=device),
        batch_size=4,
        sampler=PrioritizedSampler(max_capacity=100, alpha=0.7, beta=0.5, dtype=torch.float),
        priority_key="priority"
    )
```
