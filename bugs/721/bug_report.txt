# recovered-from-issue: https://github.com/browser-use/browser-use/issues/4269

TITLE
Bug: CodeAgent — Persistent BrowserStateRequestEvent Failure with Root CDP client not initialized

BODY
### Browser Use Version

 0.12.1

### Bug Description, Steps to Reproduce, Screenshots

## Observed Errors

### Error 1 — Repeated on every step (state retrieval)

```
ERROR [service] Failed to get browser state: Expected at least one handler to return a non-None result, but none did! ?▶ BrowserStateRequestEvent#6bb8 ✅ -> {}
```

This error repeats for **every step** of the agent loop (Steps 1–7+ observed). The event fires and resolves to an empty dict `{}` — no handler populates the browser state.

### Error 2 — Thrown on every `evaluate()` call

```
ERROR [service] Code execution error: AssertionError: Root CDP client not initialized
```

Occurs whenever the agent attempts to run JavaScript via `evaluate()`:

```python
current_url = await evaluate('window.location.href')
title = await evaluate('document.title')
page_info = await evaluate('(function(){ return {...}; })()')
```

All calls fail with the same assertion error, indicating the CDP root client was **never initialized** or was lost after the first navigation.

### Error 3 — Screenshot capture fails

```
WARNING [service] Failed to capture screenshot for step N: Expected at least one handler to return a non-None result, but none did! ?▶ BrowserStateRequestEvent#xxxx ✅ -> {}
```

Screenshot capture fails on every step because the underlying browser state is unavailable.
