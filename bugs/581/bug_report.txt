# recovered-from-issue: https://github.com/jax-ml/jax/issues/38096

TITLE
`jax.jit + jax.grad`: jit(grad(f))(x) != grad(f)(x) for `square → sqrt_abs` at smallest normal float32

BODY
### Description

JIT-compiling a gradient function changes its output at the boundary of float32 precision. For the program `square → sqrt_abs` (i.e., `sqrt(abs(x²))`), XLA simplifies the expression to `abs(x)` before differentiating, masking the chain-rule `inf` that arises in eager mode when `x²` underflows to zero.

Minimal reproducer:

```python
import numpy as np
import jax, jax.numpy as jnp

x = jnp.array([1.1754944e-38], dtype=jnp.float32)  # smallest normal float32

def program(x):
    return jnp.sqrt(jnp.abs(jnp.square(x)))  # square → sqrt_abs

jit_result   = np.asarray(jax.jit(jax.grad(lambda x: jnp.sum(program(x))))(x))
eager_result = np.asarray(jax.grad(lambda x: jnp.sum(program(x)))(x))

print("jit(grad(f)):", jit_result)    # array([1.], dtype=float32)
print("    grad(f): ", eager_result)  # array([inf], dtype=float32)
assert np.allclose(jit_result, eager_result, rtol=1e-5, atol=1e-5)  # AssertionError
```

Expected output:
```
jit(grad(f)): [inf]
    grad(f):  [inf]
```

Actual output:
```
jit(grad(f)): [1.]
    grad(f):  [inf]
```
