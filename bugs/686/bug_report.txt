### Reproduction Steps / Example Code (Python)

```python
from langchain_anthropic import ChatAnthropic

model = ChatAnthropic(model="claude-sonnet-4-6")

advisor_tool = {
    "type": "advisor_20260301",
    "name": "advisor",
    "model": "claude-sonnet-4-6",
    "max_uses": 3,
    "max_tokens": 1024,
}

model.bind_tools([advisor_tool]).invoke("hello")
```

### Description

[advisor-middleware](https://github.com/emanueleielo/advisor-middleware)'s native mode (prefer_native=True, the library's default) injects an advisor_20260301 server-side tool spec into the executor's tool list when the executor is an Anthropic model. `advisor_` isn't in `_BUILTIN_TOOL_PREFIXES` as of langchain-anthropic current main (1.4.8), so bind_tools() routes it through convert_to_anthropic_tool() instead of passing it through unchanged, which then crashes with `KeyError: 'parameters'.`
