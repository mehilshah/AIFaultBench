# recovered-from-issue: https://github.com/huggingface/smolagents/issues/1518

TITLE
[BUG] smolagents returns 422 if using OpenAIServerModel as the model, with deepinfra as the provider.

BODY
**Describe the bug**
When trying to execute a simple example using CodeAgent with OpenAIServerModel as the model, the app returns a 422. But this only happens if the model provider is Deepinfra.

**Code to reproduce the error**
```
import os

from dotenv import load_dotenv

from smolagents import CodeAgent, OpenAIServerModel, WebSearchTool

load_dotenv(override=True)

model = OpenAIServerModel(
    model_id="google/gemini-2.5-flash",
    api_base="https://api.deepinfra.com/v1/openai",
    api_key=os.getenv("DEEPINFRA_API_KEY"),
)

agent = CodeAgent(tools=[WebSearchTool()], model=model)

output = agent.run(
    "Calculate how long it takes to the fastest land animal to run through the longest continuous road. "
    "Do not consider roads that have gaps or interruptions. "
)

print("Result:", output)
```
