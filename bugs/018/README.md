# Bug 018 Reproduction Bundle

This folder contains a self-contained repro for the stale pip flag documented in TensorFlow Models.

Observed issue:
- `codebase/research/object_detection/g3doc/tf2.md:38`
- Command: `python -m pip install --use-feature=2020-resolver .`

Environment used for verification:
- Python `3.12.3`
- pip `26.1.2`

What happens:
- `pip` rejects `--use-feature=2020-resolver` with `invalid choice`.
- The command exits before any package installation starts.

Files:
- `repro.py` runs the failing command and writes the result JSON plus logs.
- `run_repro.sh` is the entry point.
- `setup_env.sh` checks the local Python/pip runtime.
- `requirements.txt` is intentionally empty because the repro uses only stdlib and pip.
- `reproduction.json`, `repro_stdout.log`, and `repro_stderr.log` are generated by the repro.

Run:
```bash
bash run_repro.sh
```
