Title: Getting timestamps using NeMo tensor loading
Date: 2026-01-20T16:07:27+00:00
URL: https://github.com/NVIDIA-NeMo/NeMo/issues/15305

Description:
Using NeMo tensor loading (https://github.com/NVIDIA-NeMo/NeMo/pull/15265/)
Occasionally, the `timestamp[word]` and `timestamp[segment]` fields are left blank.

This file: [timestamp.zip](https://github.com/user-attachments/files/24741813/timestamp.zip)

Testcase:
````python
from nemo.collections.asr.models import EncDecMultiTaskModel
model = EncDecMultiTaskModel.from_pretrained("nvidia/canary-1b-v2")

import librosa
audio, sr = librosa.load('timestamp.wav', sr=16000)

hypotheses = model.transcribe(
    audio=audio,
    source_lang='fr', target_lang='fr', timestamps=True,
    batch_size=1,
    return_hypotheses=True,
)
print(hypotheses)
````
