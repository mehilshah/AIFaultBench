TITLE
Significant Accuracy Drop After Converting ViT-S Transformer from .pth to ONNX (~7%)

BODY
**Describe the bug**
I am experiencing a significant accuracy drop (~7%) after converting my ViT-S Transformer model from .pth format to ONNX. The model performs well in PyTorch inference, but after conversion, the ONNX model produces noticeably worse results. Here are the details of my workflow:

**To Reproduce**
Steps to reproduce the behavior:
I used the following code to export the model at [onnx_export.py](https://github.com/huggingface/pytorch-image-models/blob/main/onnx_export.py)

1. This is my comment when exporting: python3 onnx_export.py vit-s_baseline.onnx --model vit_small_patch16_224.augreg_in21k_ft_in1k --num-classes 1000  --img-size 224

2. This is my comment for evaluate .pth accuracy (result is 81.374%): python3 [validate.py](https://github.com/huggingface/pytorch-image-models/blob/main/validate.py) --data-dir ./data/ImageNet --model vit_small_patch16_224.augreg_in21k_ft_in1k --pretrained

3. This is my comment for evaluate .onnx accuracy (result is 74.190%): python3 [onnx_validate.py](https://github.com/huggingface/pytorch-image-models/blob/main/onnx_validate.py) ImageNet/validation --onnx-input vit-s_baseline.onnx


**Expected behavior**
The ONNX model should produce predictions with accuracy close to the PyTorch model.

**Screenshots**
If applicable, add screenshots to help explain your problem.

**Desktop (please complete the following information):**
 - OS: [Ubuntu 20.04]
 - PyTorch Version: 2.3.1+cpu

**Additional context**
The accuracy of the PyTorch model on ImageNet1k is 81.374%, while the ONNX model achieves only 74.190%.
