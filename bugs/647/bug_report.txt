Claude had the following to say:
langgraph-cli==0.4.29 with [inmem] extra pulls in langgraph-api == 0.12.0.dev3 and langgraph-runtime-inmem == 0.31.0.dev9
The error occurred because these two dev packages are out of sync with each other — langgraph-runtime-inmem 0.31.0.dev9 was written expecting langgraph-api to have a LSD_PROM_METRICS_ENABLED attribute that doesn't exist yet in 0.12.0.dev3.

Resolved by downgrading :
pip install --force-reinstall langgraph-runtime-inmem==0.30.0 langgraph-api==0.10.0

Could the extra [inmem] be limited to released packages?
