Hello,

I'm encountering a TypeError when evaluating a sentence similarity model using EmbeddingSimilarityEvaluator on an A100 GPU.

The same code works fine on CPU.

I've tested it with both sentence-transformers versions 3.4.1 and 5.0.0, and the issue persists.

Minimal reproducible code:
```python

from datasets import load_dataset
from sentence_transformers.evaluation import EmbeddingSimilarityEvaluator, SimilarityFunction
from sentence_transformers import SentenceTransformer

# Load the STSB dataset
eval_dataset = load_dataset("sentence-transformers/stsb", split="validation")

# Initialize the evaluator
dev_evaluator = EmbeddingSimilarityEvaluator(
    sentences1=eval_dataset["sentence1"],
    sentences2=eval_dataset["sentence2"],
    scores=eval_dataset["score"],
    main_similarity=SimilarityFunction.COSINE,
)

model_name = "sentence-transformers/all-mpnet-base-v2"
model = SentenceTransformer(model_name)

# Load model on GPU
# model = SentenceTransformer(model_name, device="cuda" if torch.cuda.is_available() else "cpu", cache_folder=os.environ["HF_HOME"])


# Run evaluation manually
print(dev_evaluator(model))
```
