# Generate a segmentation map

    images=image,
    segmentation_maps=seg_map,
    return_tensors="pt",
)

### Expected behavior

Looks like the function `convert_segmentation_map_to_binary_masks`, which is imported from the slow image processor, can not work with tensors that are on CUDA.

The function in the slow image processor is adapted from the same function from MaskFormer. However, MaskFormer's fast image processor have the fast implementation of this function. We can just use it.

I will submit a PR.
