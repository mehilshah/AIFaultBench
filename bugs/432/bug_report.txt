# recovered-from-issue: https://github.com/pyg-team/pytorch_geometric/issues/10160

TITLE
CI Failing on Python 3.9 Torch 2.5 due to Upstream `pgmpy` changes

BODY
### 🐛 Describe the bug

The CI test for Torch 2.5 Ubuntu fails due to upstream changes in the dependency `pgmpy` that break for python <3.10. Specifically the `|` feature in function defs:
`TypeError: unsupported operand type(s) for |: 'type' and 'type'`.
I'm not sure if they still officially support python 3.9, Their documentation suggests they do, but their CI seems to only test for python 3.12/3.13, and it looks like they just dropped 3.10: https://github.com/pgmpy/pgmpy/blob/dev/.github/workflows/ci.yml

Proposed fixes:

1. bump our python version to 3.10 for our CI tests for torch 2.5
2. submit a PR upstream to fix pipes
3. skip our tests for `pgm_explainer` in python version <3.10
