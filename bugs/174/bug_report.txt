Title: GrammarError: Rule 'anycase' used but not defined (in rule pipesyn)
Date: 2023-10-22T00:13:29+00:00
URL: https://github.com/lark-parser/lark/issues/1355

Description:
When attempting to load a small grammar, Lark reports that a rule alias name is "used but not defined".  It's rather obviously defined, as the only usage of the name is the alias.  The specific alias that gets flagged varies - running the example below flags `anycase`, `anyof`, and `mask`, seemingly randomly.

The grammar is intended to recognize simple operand strings like:

```
AnYcA mIXEd

ONEs

zero ANYOF
```

To reproduce, run the following:

```python
import lark

grammar = '''
start: pipesyn
pipesyn: ["any"i ("c"i ("a"i ("s"i ("e"i)? )? )? )? -> anycase]
 | [("mixed"i
 | "one"i ("s"i)?
 | "zero"i ("s"i)?) -> mask]
 | ["anyo"i ("f"i)? -> anyof]
'''

parser = lark.Lark(grammar, parser="lalr")
```

You'll get an exception like the following:
