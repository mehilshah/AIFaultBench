### Issue description

### Problem

`pyannote-audio>=3.3.2,<4.0.0` declares a dependency on `lightning>=2.0.1`. However, the `lightning` package on PyPI has been **quarantined by PyPI admins** and is no longer installable by any client:

> "This project has been quarantined. PyPI Admins need to review this project before it can be restored. While in quarantine, the project is not installable by clients."

See: https://pypi.org/project/lightning/

This makes `pyannote-audio==3.3.2` (and `3.4.0`) effectively uninstallable via pip/uv.

### Error

```
ERROR: Could not find a version that satisfies the requirement lightning>=2.0.1 (from pyannote-audio)
ERROR: No matching distribution found for lightning>=2.0.1
```

With `uv`:
```
Because there are no versions of lightning and pyannote-audio>=3.3.2,<=3.4.0 depends on lightning>=2.0.1,
we can conclude that pyannote-audio>=3.3.2,<=3.4.0 cannot be used.
```

### Root Cause

The `lightning` package is a meta-package that includes `pytorch-lightning`. The functional equivalent `pytorch-lightning>=2.0.1` is still available and installable on PyPI. The dependency in `pyannote-audio` should be updated to reference `pytorch-lightning` instead of (or in addition to) `lightning`.

### Suggested Fix

In `requirements.txt` / `setup.cfg` / `pyproject.toml`, replace:
```
lightning>=2.0.1
```
with:
```
pytorch-lightning>=2.0.1
```

Or declare both as alternatives if `lightning` is restored in the future.

### Workaround (for users until this is fixed)

```bash
pip install pytorch-lightning>=2.0.1
pip install pyannote-audio==3.3.2 --no-deps
pip install asteroid-filterbanks>=0.4 einops>=0.6.0 omegaconf>=2.1 \
    "pyannote.core>=5.0" "pyannote.database>=5.0" "pyannote.metrics>=3.2" \
    "pyannote.pipeline>=3.0" rich semver "speechbrain>=1.0"
```
