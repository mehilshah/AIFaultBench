### Reproduction

I am trying to use deepspeed for inference. The code hangs at the line `model.generate(data, max_new_tokens = 5)` in the below code. This hanging never occurs on the first batch. This only occurs when using multiple processes with deepspeed. If I do not use deepspeed or I only use a single GPU, the code runs correctly. I've tried adding `accelerator.pad_across_processes(outputs)`, but that did not fix the issue. 

```

input_ids = tokenizer([prompt] * len(notes['Report_Text']), notes['Report_Text'].tolist(), 
        return_tensors="pt", truncation="only_second", padding='max_length', return_overflowing_tokens=True,
       stride=128, return_offsets_mapping=True)  
chunk_to_note_map = input_ids.pop("overflow_to_sample_mapping")
input_ids = input_ids.input_ids

dataloader = DataLoader(
        input_ids, shuffle=False, batch_size=batch_size 
    )
    
chunk_dataloader = DataLoader(
        chunk_to_note_map, shuffle=False, batch_size=batch_size 
    )


model, dataloader, chunk_dataloader = accelerator.prepare(model, dataloader, chunk_dataloader)

for data, note_idx in tqdm(zip(dataloader, chunk_dataloader), disable=not accelerator.is_local_main_process):
        outputs = model.generate(data, max_new_tokens = 5) 
        outputs = accelerator.gather(outputs)
        note_idx = accelerator.gather(note_idx)
        preds = tokenizer.batch_decode(outputs, skip_special_tokens=True)
```

### Expected behavior

```Shell
The code hangs at the line `outputs = model.generate(data, max_new_tokens = 5)`, but this should not happen.
```
