TITLE
Python: Bug: AzureChatCompletion StreamWrapper AttributeError: 'usage' missing in Semantic Kernel Group Chat Orchestration

BODY
**Describe the bug**
When running a Group Chat Orchestration with Azure AI Foundry Tracing enabled using the semantic-kernel SDK, the orchestration fails with an AttributeError: 'StreamWrapper' object has no attribute 'usage' during streaming responses. This causes the group chat to crash and prevents completion of the workflow.

**To Reproduce**
Steps to reproduce the behavior:
1. Create a GroupChatOrchestration with multiple agents using the Semantic Kernel GroupChatManager and InProcessRuntime.
2. Enable Azure AI Foundry tracing and OpenTelemetry instrumentation as shown in the code snippet.
3. Run the orchestration with a streaming agent (AzureChatCompletion service).
4. Observe the error in logs.

**Expected behavior**
The group chat orchestration should execute successfully with tracing enabled and should:
1. Correctly capture token usage, including intermediate and final LLM calls.
2. Complete the prompt execution and return results without crashing.

class TracingManager:
    """Enhanced tracing manager with plugin-level tracing support."""

    def __init__(self):
        self.project_client = None
        self.connection_string = None
        self.tracer = trace.get_tracer(__name__)
        self._initialized = False

    async def initialize(self):
        """Initialize Azure AI Foundry tracing configuration."""
        if self._initialized:
            return

        try:
            log.info("🔍 Initializing Azure AI Foundry tracing...")

            self.project_client = AIProjectClient(
                credential=DefaultAzureCredential(),
                endpoint=AZURE_AI_FOUNDRY_PROJECT_ENDPOINT,
            )

            self.connection_string = (
                self.project_client.telemetry.get_connection_string()
            )
            log.info("✅ Retrieved Application Insights connection string")

            configure_azure_monitor(connection_string=self.connection_string)
            log.info("✅ Azure Monitor OpenTelemetry configured successfully")
   
            OpenAIInstrumentor().instrument()

            self._initialized = True

        except Exception as e:
            log.error(f"❌ Failed to initialize Azure AI Foundry tracing: {str(e)}")
            log.error(f"Tracing error details: {traceback.format_exc()}")
            self._initialized = False

    def get_tracer(self):
        """Get the OpenTelemetry tracer instance."""
        return self.tracer
