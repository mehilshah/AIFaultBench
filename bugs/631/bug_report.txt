[DayZ Parameters] DayZ parameter validation does not validate DAYZ_SPEC_VERSION

### Error Description

Currently, parameter validation is not validating that the `'DAYZ_SPEC_VERISON'` matches the current spec version. We should add a validation check that verifies that the spec version provided is the expected version, and error if it is not.  

### Steps to reproduce

```python
dayz_parameters = SingleTableDayZSynthesizer.create_parameters(data, metadata)
dayz_parameters['DAYZ_SPEC_VERSION'] = 'V1000'

SingleTableDayZSynthesizer.validate_parameters(metadata, dayz_parameters)
```
