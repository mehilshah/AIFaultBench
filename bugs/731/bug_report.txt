### Problem description

Minimax uses different API endpoints for mainland China and international users. Previously, the codebase defaulted to the mainland endpoint:
```
https://api.minimaxi.io/v1
```
However, international users must use:
```
https://api.minimax.io/v1
```
Because the mainland endpoint was set as the default, international users could encounter confusing authentication errors if they did not manually update the configuration.

```
openai.AuthenticationError: Error code: 401 - {'type': 'error', 'error': {'type': 'authorized_error', 'message': 'invalid api key (2049)', 'http_code': '401'}, 'request_id': '065a9f88e8f5db97a45c1f42651f8e7e'}
```

### Reproducible example code

The Python snippets:
test_minimax_agent.py
```python
from camel.agents import ChatAgent
from camel.models import ModelFactory
from camel.types import ModelPlatformType, ModelType


sys_msg = "You are a helpful assistant."
usr_msg = """Who is the best basketball player in the world?
Tell about his career.
"""

model = ModelFactory.create(
    model_platform=ModelPlatformType.MINIMAX,
    model_type=ModelType.MINIMAX_M2_7,
)
agent = ChatAgent(
    system_message=sys_msg,
    model=model,
)

response = agent.step(usr_msg)
print(response.msgs[0].content)
```

Command lines:

```bash
python examples/agents/test_minimax_agent.py
```
