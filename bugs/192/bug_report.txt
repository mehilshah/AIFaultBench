Title: Real-IAD dataset categories in Anomalib don’t match Hugging Face dataset
Date: 2025-09-03T16:25:13+00:00
URL: https://github.com/open-edge-platform/anomalib/issues/2929

Description:
### Describe the bug

The `CATEGORIES` variable hard-coded in `anomalib.data.datasets.image.realiad` does not match the category list published in the official Real-IAD dataset on Hugging Face. This causes confusion when trying to load or evaluate the dataset, since the labels don’t align with the released data.
