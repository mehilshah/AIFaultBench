# recovered-from-issue: https://github.com/pyg-team/pytorch_geometric/issues/10497

TITLE
"Data" object from older version of PyG

BODY
### 🐛 Describe the bug

I am trying to use an LMDB file (obtained from the [Open Catalyst Project](https://fair-chem.github.io/catalysts/datasets/oc20.html#initial-structure-to-relaxed-structure-is2rs-and-initial-structure-to-relaxed-energy-is2re-tasks)) that contains `torch_geometric.data.data.Data` objects as datapoints. When trying to open the individual datapoints (I am assuming they were created with version of pytorch-geometric <2, per the date they were created - Dec 2021), I get the following error:

```RuntimeError: The 'data' object was created by an older version of PyG. If this error occurred while loading an already existing dataset, remove the 'processed/' directory in the dataset's root folder and try again.```

Unfortunately, no such `processed/` directory exists, as it is extracted directly from the LMDB file. I have pickled a single datapoint and I am attaching it, for the error to be reproduced.

[torch_geom_data.tar.gz](https://github.com/user-attachments/files/22852630/torch_geom_data.tar.gz)

```
import pickle
with open('torch_geom_data.pkl', 'rb') as pkl:
    datapoint = pickle.load(pkl)
print(type(datapoint))
print(datapoint)
```
