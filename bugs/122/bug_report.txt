Title: [Bug]: Manually setting net_arch=None causes crash when loading model
Date: 2024-05-17T17:32:12+00:00
URL: https://github.com/DLR-RM/stable-baselines3/issues/1928

Description:
### 🐛 Bug

I've run into this issue a few times, since I use command line args in a wrapper script where I default `net_arch` to `None`, and I pass that to `policy_kwargs`.

I was able to fix it locally by changing [this line](https://github.com/DLR-RM/stable-baselines3/blob/6c00565778e5815e4589afc7499aafbd020535ae/stable_baselines3/common/base_class.py#L695) from
```python
if "net_arch" in data["policy_kwargs"] and len(data["policy_kwargs"]["net_arch"]) > 0:
```
to
```python
if data.get("policy_kwargs", {}).get("net_arch"):
```

### To Reproduce

```python
import gymnasium as gym

from stable_baselines3 import PPO

env = gym.make("CartPole-v1")

model = PPO("MlpPolicy", env, policy_kwargs=dict(net_arch=None))
model.learn(total_timesteps=5000)
model.save("ppo_cartpole")

del model

model = PPO.load("ppo_cartpole")
```
