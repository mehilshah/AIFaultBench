# recovered-from-issue: https://github.com/jax-ml/jax/issues/38099

TITLE
`jax.jit + jnp.log + jnp.exp`: jit(log(exp(x))) hides exp overflow — XLA rewrites log(exp(x)) to x

BODY
### Description


XLA's algebraic rewrite `log(exp(x)) → x` suppresses the `inf` that eager mode produces when `exp(x)` overflows in float32 (at x > 88.72). `jit(log(exp(89)))` returns `89.0` while eager correctly returns `inf`.

Minimal reproducer:

```python
import numpy as np
import jax, jax.numpy as jnp

x = jnp.array(89.0, dtype=jnp.float32)  # exp(89) overflows in float32

jit_result   = float(jax.jit(lambda x: jnp.log(jnp.exp(x)))(x))
eager_result = float(jnp.log(jnp.exp(x)))

print(f"jit(log(exp(89)))  = {jit_result}")   # 89.0
print(f"    log(exp(89))   = {eager_result}")  # inf
assert jit_result == eager_result  # AssertionError
```

Expected output:
```
jit(log(exp(89))) = inf
    log(exp(89))  = inf
```

Actual output:
```
jit(log(exp(89))) = 89.0
    log(exp(89))  = inf
```
