Title: Sweep runs overwrite each other because output_dir from base config is reused

- [x] I searched previous [Bug Reports](https://github.com/axolotl-ai-cloud/axolotl/labels/bug) didn't find any similar reports.

### Expected Behavior

Each sweep permutation should automatically generate a unique output_dir (for example by appending the sweep parameters or a timestamp), so that results are not overwritten.

### Current behaviour

When running training with the `--sweep` option, all generated runs share the same output_dir defined in the base `config.yml`. As a result, multiple sweep permutations overwrite each other’s checkpoints and logs.

> But there is only one out_dir(./outputs/sweep-test in this case) and it is overwritten. (final output file only contains last permutation result)

### Steps to reproduce

1. Create a base `config.yml` with output_dir, for example:
```yaml
base_model: NousResearch/Llama-3.2-1B

# only use 1% of the training split for quick smoke test
datasets:
  - path: teknium/GPT4-LLM-Cleaned
    type: alpaca
    split: train
    split_percent: 1

output_dir: ./outputs/sweep-test

adapter: lora
lora_model_dir:

sequence_len: 512

lora_r: 8
lora_alpha: 16
lora_target_modules:
  - q_proj
  - v_proj

gradient_accumulation_steps: 1
micro_batch_size: 1
# stop after 20 steps (quick test)
max_steps: 20

special_tokens:
  pad_token: "<|end_of_text|>"
```

2. Define a `sweep.yaml` with multiple values, for example:
```yaml
_:
  # This section is for dependent variables we need to fix
  - load_in_8bit: false
    load_in_4bit: false
    adapter: lora
  - load_in_8bit: true
    load_in_4bit: false
    adapter: lora

# These are independent variables
learning_rate: [0.0003, 0.0006]
lora_r:
  - 16
  - 32
lora_alpha:
  - 16
  - 32
  - 64
```
4. Run:
```bash
axolotl train config.yml --sweep sweep.yaml
```

### Possible solution

- Create a **dedicated subdirectory** for each permutation under the base `output_dir`  
  - e.g., `output_dir/sweep001/`, `output_dir/sweep002/`, ...  
  - Prevents overwriting between permutations  
  - Each subdirectory contains a `README.md` describing the hyperparameters used for that run
