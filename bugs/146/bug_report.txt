Title: SentenceTransfomer tokenizer result is not consistent with tokenize reuslt in encode
Date: 2025-03-10T05:41:15+00:00
URL: https://github.com/huggingface/sentence-transformers/issues/3262

Description:
I tested with this model:
https://huggingface.co/Alibaba-NLP/gte-Qwen2-7B-instruct

with following code:
```
from sentence_transformers import SentenceTransformer, models
word_embedding_model = models.Transformer(model_name_or_path="Alibaba-NLP/gte-Qwen2-7B-instruct")
pooling_model = models.Pooling(word_embedding_model.get_word_embedding_dimension(), pooling_mode="lasttoken", pooling_mode_lasttoken=True)
normalize = models.Normalize()
model = SentenceTransformer(modules=[word_embedding_model, pooling_model,normalize], device="cpu")
tokenizer = model.tokenizer
embeddings = model.encode("Hello test", normalize_embeddings=True, output_value='sentence_embedding')
print("\nSF embed case 0 \"Hello test\"..........................................")
print(len(embeddings))
try:
    for i in range(0, len(embeddings)):
        cur = embeddings[i]
        print(cur[0:6],"...",cur[-6:])
except:
    if len(embeddings) == 1:
        embeddings = embeddings[0]
    print(embeddings[0:6],"...",embeddings[-6:])

print("\nSF embed case 1 \" test\"..........................................")
embeddings = model.encode(" test", normalize_embeddings=True, output_value='sentence_embedding')
print(len(embeddings))
if len(embeddings) == 1:
    embeddings = embeddings[0]
print(embeddings[0:6],"...",embeddings[-6:])

print("\nSF embed case 2 \"test\"..........................................")
embeddings = model.encode("test", normalize_embeddings=True, output_value='sentence_embedding')
print(len(embeddings))
if len(embeddings) == 1:
    embeddings = embeddings[0]
print(embeddings[0:6],"...",embeddings[-6:])
```
