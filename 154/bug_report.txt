### Reproduction

Simple example

```py
from transformers.image_utils import load_image
import transformers
import torch

url = "http://images.cocodataset.org/val2017/000000039769.jpg"
image = load_image(url)
image_processor = transformers.SegformerImageProcessor()
image = image_processor(image, return_tensors="pt")

backbone = transformers.ResNetConfig(
    out_features=["stage4"],
    image_size=512,
)
config = transformers.TvpConfig(
    backbone_config=backbone,
    backbone=None,
    use_timm_backbone=False,
    use_pretrained_backbone=False,
    max_img_size=512,
)
model = transformers.TvpModel(config)

model(**image)
```

Adding `type_vocab_size=2` to model config solves the problem.

### Expected behavior

`type_vocab_size` does not have a default value and is not even mentioned in documentation.

Probably adding setting default value to 2 is optimal, because all the TVP models on Huggingface Hub have `type_vocab_size=2`.

Also it would be good to add it to docstring.
