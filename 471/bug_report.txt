TITLE
Bug in data.transforms.transforms_gen.RandomCrop

BODY
Attempting to print a RandomCrop to the console or get a string representation thereof results in "ValueError: Function has keyword-only parameters or annotations, use getfullargspec() API which can support them"

## To Reproduce

Simple code snipped to reproduce:

```python
from detectron2.data.transforms import RandomCrop
print(RandomCrop("relative", (100, 100)))
```

The issue can be recreated with arbitrary (valid) arguments to RandomCrop.

## Expected behavior

Probably to print a summary of the object as with the other transforms.
