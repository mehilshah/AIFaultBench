# recovered-from-issue: https://github.com/Lightning-AI/pytorch-lightning/issues/21580

TITLE
Wrong typehint for device_mesh in FSDP

BODY
### Bug description

The type hint of `device_mesh` in FSDP is not correct. The current value is `Optional[Union[tuple[int], "DeviceMesh"]]`, which causes a configuration validation error when using the CLI and setting `device_mesh` as a tuple. Indeed, if a tuple, `device_mesh` must be of length 2: (replication size, sharding size).

The correct value for the type hint is `Optional[Union[tuple[int, int], "DeviceMesh"]]`.

### What version are you seeing the problem on?

v2.5

### How to reproduce the bug

```python
fit:
    trainer:
        strategy:
            class_path: lightning.pytorch.strategies.FSDPStrategy
            init_args:
                sharding_strategy: HYBRID_SHARD
                device_mesh: [1, 4]
```
