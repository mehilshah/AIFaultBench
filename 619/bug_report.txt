TITLE
Issue with inferring batch size when using PyTorch Lightning

BODY
### 🐛 Describe the bug

I have been using PyTorch Lightning to accelerate some of the training and remove some boiler code. I have run into an issue.

I have been using the LightningDataModule to encapsulate the logic of the dataset generation and the LightningModule to run my model. I have manually set the batch size, but Torch Lightning is inferring the batch size on its own and just using the node number which causes issues with logging metrics. Is there a solution for this problem, as it slows the entire process down?

I am attaching the error message and the validation method where the error is observed as well as the error message.

The code I am using;
```
def validation_step(self, batch, batch_idx):
        y_pred = self(batch)

        batch_size = batch.num_graphs

        loss = F.mse_loss(y_pred, batch.y)

        self.log('val_loss', loss)
        mape = self.mape(y_pred, batch.y)
        mse = self.mse(y_pred, batch.y)
        mae = self.mae(y_pred, batch.y)

        self.log('val_mae', mae, batch_size=batch_size, on_step=True, on_epoch=True, prog_bar=True)
        self.log('val_mse', mse, batch_size=batch_size, on_step=True, on_epoch=True, prog_bar=True)
        self.log('val_mape', mape, batch_size=batch_size, on_step=True, on_epoch=True, prog_bar=True)
```

The error message;
`pytorch_lightning/utilities/data.py:78: Trying to infer the ``batch_size`` from an ambiguous collection. The batch size we found is 3161. To avoid any miscalculations, use ``self.log(..., batch_size=batch_size)``.`
