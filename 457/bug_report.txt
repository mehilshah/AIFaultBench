# recovered-from-issue: https://github.com/facebookresearch/detectron2/issues/334

TITLE
densepose eval metrics differ on gpu and cpu

BODY
Evaluation with pretrained resnet50+fpn from MODEL ZOO for densepose task produces different densepose AP depending on which MODEL.DEVICE I select. In the mean time bbox AP are the same

## How To Reproduce the Issue

1. `CUDA_VISIBLE_DEVICES=2 python train_net.py --config-file configs/densepose_rcnn_R_50_FPN_s1x.yaml --eval-only --num-gpus 1 MODEL.WEIGHTS model_final_dd99d2.pkl`

produces

```
[11/18 10:14:33 d2.engine.defaults]: Evaluation results for densepose_coco_2014_minival in csv format:
[11/18 10:14:33 d2.evaluation.testing]: copypaste: Task: bbox
[11/18 10:14:33 d2.evaluation.testing]: copypaste: AP,AP50,AP75,APs,APm,APl
[11/18 10:14:33 d2.evaluation.testing]: copypaste: 57.8333,87.1848,62.8350,29.8270,56.3500,71.2617
[11/18 10:14:33 d2.evaluation.testing]: copypaste: Task: densepose
[11/18 10:14:33 d2.evaluation.testing]: copypaste: AP,AP50,AP75,APm,APl
[11/18 10:14:33 d2.evaluation.testing]: copypaste: 49.8130,86.5007,51.6506,44.2049,51.0755
```

2. `CUDA_VISIBLE_DEVICES=2 python train_net.py --config-file configs/densepose_rcnn_R_50_FPN_s1x.yaml --eval-only --num-gpus 1 MODEL.WEIGHTS model_final_dd99d2.pkl MODEL.DEVICE cpu`

produces

```
[11/12 14:51:13] d2.engine.defaults INFO: Evaluation results for densepose_coco_2014_minival in csv format:
[11/12 14:51:13] d2.evaluation.testing INFO: copypaste: Task: bbox
[11/12 14:51:13] d2.evaluation.testing INFO: copypaste: AP,AP50,AP75,APs,APm,APl
[11/12 14:51:13] d2.evaluation.testing INFO: copypaste: 57.8343,87.1848,62.8350,29.8270,56.3501,71.2641
[11/12 14:51:13] d2.evaluation.testing INFO: copypaste: Task: densepose
[11/12 14:51:13] d2.evaluation.testing INFO: copypaste: AP,AP50,AP75,APm,APl
[11/12 14:51:13] d2.evaluation.testing INFO: copypaste: 0.6251,1.1449,0.6186,0.0000,1.1336
```




## Expected behavior

MODEL.DEVICE parameter in config should not affect metrics evaluated
