# recovered-from-issue: https://github.com/jax-ml/jax/issues/38105

TITLE
`jax.numpy.heaviside(x1, x2)` is supposed to compute the Heaviside step function, returning `0` when `x1 < 0`, `1` when `x1 > 0`, and `x2` when `x1 == 0`

BODY
### Description

```python
import numpy as np
import jax
import jax.numpy as jnp

jax.config.update("jax_enable_x64", True)

x1_f32 = np.float32(np.nan)
x2_f32 = np.float32(-1.0)

x1_f64 = np.float64(np.nan)
x2_f64 = np.float64(-1.0)

print(np.heaviside(x1_f32, x2_f32))   # nan   ← correct
print(jnp.heaviside(x1_f32, x2_f32))  # -1.0  ← BUG: should be nan

print(np.heaviside(x1_f64, x2_f64))   # nan   ← correct
print(jnp.heaviside(x1_f64, x2_f64))  # -1.0  ← BUG: should be nan
```

The same behavior occurs under `jax.jit`:

```python
print(jax.jit(jnp.heaviside)(jnp.array(x1_f32), jnp.array(x2_f32)))  # -1.0
print(jax.jit(jnp.heaviside)(jnp.array(x1_f64), jnp.array(x2_f64)))  # -1.0
```

Expected behavior

```text
nan
nan
nan
nan
```

Actual behavior

```text
nan
-1.0
nan
-1.0
```

Additional cases

The issue is not specific to `x2=-1.0`. When `x1=nan`, JAX returns `x2` for any non-NaN `x2`:

```python
import numpy as np
import jax.numpy as jnp

for x2 in [
    np.float32(-1.0),
    np.float32(0.0),
    np.float32(0.5),
    np.float32(1.0),
    np.float32(np.nan),
]:
    x1 = np.float32(np.nan)
    print(f"x2={x2!r}")
    print("  numpy:", np.heaviside(x1, x2))
    print("  jax:  ", jnp.heaviside(jnp.array(x1), jnp.array(x2)))
```

Observed:

```text
x2=np.float32(-1.0)
  numpy: nan
  jax:   -1.0

x2=np.float32(0.0)
  numpy: nan
  jax:   0.0

x2=np.float32(0.5)
  numpy: nan
  jax:   0.5

x2=np.float32(1.0)
  numpy: nan
  jax:   1.0

x2=np.float32(nan)
  numpy: nan
  jax:   nan
```
