### Reproduction

```python
import torch
from accelerate import Accelerator

accelerator = Accelerator()
process_tensor = torch.arange(accelerator.num_processes) + 1 + (4 * accelerator.process_index)
process_tensor = process_tensor.to(accelerator.device)

sum_reduced_tensor = accelerator.reduce(process_tensor, reduction="sum")
accelerator.print(sum_reduced_tensor)
# print out: tensor([16, 20, 24, 28], device='cuda:0')

mean_reduced_tensor = accelerator.reduce(process_tensor, reduction="mean")
accelerator.print(mean_reduced_tensor)
# print out the same values: tensor([16, 20, 24, 28], device='cuda:0')
```

### Expected behavior

```Shell
`sum_reduced_tensor` and `mean_reduced_tensor` are the same. weird. I intended to get a mean tensor `mean_reduced_tensor` that averages all tensors from each process but failed.
```
