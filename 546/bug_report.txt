### Reproduction

Let's say I want to do multi-node with 2 nodes, 1 gpu on each node
In `accelerate config` you are asked the following:
> How many GPU(s) should be used for distributed training? [1]: 2
> What GPU(s) (by id) should be used for training on this machine as a comma-seperated list? [all]: 0

You would assume that this is correct. The GPU id on each node is indeed 0 and the total number of GPUs is 2. So this should work, but it doesn't. What happens then if you launch your script is that it completely ignores the multi-node part and just starts your script as if you are doing single-node. You can print the accelerator.state to see that it is indeed not doing multi-node. Now if you change `gpus` in the config from `gpus='0'` to `gpus='all'`, then it works. Very confusing behaviour.
