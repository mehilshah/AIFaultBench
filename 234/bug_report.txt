Title: `error_if` sometimes raises `ValueError` instead of `EquinoxRuntimeError` depending on execution order
Date: 2025-12-22T10:58:21+00:00
URL: https://github.com/patrick-kidger/equinox/issues/1156

Description:
## Description

Calling `equinox.error_if` is supposed to raise an `EquinoxRuntimeError`. Since jax 0.7.2, this appears to be broken when you call a jitted function *first* without the error condition, and *then* with the error condition triggering.

When the bug is triggered, a `ValueError` is raised instead, with equinox incorrectly claiming that I am not using "filter_jit" even though I am.

Reversing the order of calls does not trigger this bug -- when the first time the function is jitted the error *is* raised, it will correctly raise `EquinoxRuntimeError` on all subsequent calls.

Using `@jax.jit` rather than `@equinox.filter_jit` has the same inconsistency, where it raises a `JaxRuntimeError` in the expected case, and incorrectly a ValueError when first called without the error being hit.

## Which versions are affected?

Python version: 3.12

equinox version: 0.13.2

JAX version:
 * reproduced with latest version `jax==0.8.2`
 * reproduced with `jax==0.7.2`
 * NOT reproducible with `jax==0.7.1` and earlier versions

## Minimal reproducer

```python
import equinox
import jax.numpy as jnp

@equinox.filter_jit
def foo(x):
    # Adding a debug print makes the ValueError bug go away!
    # jax.debug.print("Inside foo with x = {}", x)

    return equinox.error_if(x, x > 0.0, "my message")

def foo_without_error():
    # Calls foo without raising an error
    return foo(jnp.array(-1.0))

def foo_with_error():
    # Calls foo in a way that raises an error, printing the error type
    try:
        foo(jnp.array(1.0))
    except Exception as e:
        print("Exception type:", type(e))


# Calling the function first without error, then with error, results in a ValueError
# rather than the expected EquinoxRuntimeError.
# Reversing these 2 lines does not trigger the bug.
foo_without_error()
foo_with_error()
```

Actual output:
```
Exception type: <class 'ValueError'>
```

Expected output:
```
Exception type: <class 'EquinoxRuntimeError'>
```
