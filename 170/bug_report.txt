Title: [Bug]: RandomThinPlateSpline ignores same_on_batch=True
Date: 2026-01-07T09:00:43+00:00
URL: https://github.com/kornia/kornia/issues/3464

Description:
### 🐛 Describe the bug

`RandomThinPlateSpline` does not consistently apply the same Thin Plate Spline transformation across all images in a batch when `same_on_batch=True`.
Users would expect:
```python
aug = RandomThinPlateSpline(p=1.0, same_on_batch=True)
y = aug(x)
```
to apply identical control points to every image in the batch.

This is because `RandomThinPlateSpline.generate_parameters` sampled destination control points independently per batch element, even when `same_on_batch=True`.
However, prior to the fix the behaviour was inconsistent and different TPS parameters were sometimes sampled internally per-image.


### 🔄 Steps to Reproduce

```bash
1. Add the following Code.
```

### 💻 Minimal Code Example

```python
import kornia
import torch
from kornia.augmentation import RandomThinPlateSpline

torch.manual_seed(42)
x = torch.randn(4, 3, 32, 32)
aug = RandomThinPlateSpline(p=1.0, same_on_batch=True)
y = aug(x)
params = aug._params
src = params["src"]
dst = params["dst"]

# These should match across the batch
print(torch.allclose(src[0], src[1]))
print(torch.allclose(dst[0], dst[1]))
```

###  Expected behavior

All control points should be identical when `same_on_batch=True`.

###  Actual behavior

The control point sets may differ across samples in the same batch.
