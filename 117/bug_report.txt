Title: Error when calling classes through Fire
Date: 2024-05-17T14:35:28+00:00
URL: https://github.com/clearml/clearml/issues/1268

Description:
## Describe the bug
I try to run python script using [Python Fire](https://github.com/google/python-fire) and ClearML packages.
In my case I call classes using Fire interface and getting error just by doing `from clearml import Task` even without creating `Task`.

## To reproduce
This is simple code example to reproduce:

```python
from clearml import Task
import fire


class Add:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __call__(self, verbose: bool = False):
        res = self.x + self.y
        if verbose:
            print(f"x = {self.x}")
            print(f"y = {self.y}")
            print(f"x + y = {res}")
        return res


class Mult:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __call__(self, verbose: bool = False):
        res = self.x * self.y
        if verbose:
            print(f"x = {self.x}")
            print(f"y = {self.y}")
            print(f"x * y = {res}")
        return res


if __name__ == "__main__":
    # Task.init(project_name="examples", task_name="Fire dict command")
    fire.Fire(
        {
            "add": Add,
            "multiply": Mult,
        }
    )
```
I am running the code like this:
`python tmp.py multiply --x 2 --y 10 --verbose`

And getting this error:
