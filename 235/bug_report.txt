Title: Calling eqx.Module method invokes user defined __getattr__
Date: 2024-07-24T23:01:06+00:00
URL: https://github.com/patrick-kidger/equinox/issues/791

Description:
Hi team, thank you for providing Equinox. I have encountered a new issue in 0.11.4 that has not been a problem up to 0.11.3. When I have a `eqx.Module` based class with a user defined `__getattr__, `calling a method now calls `__getattr__` twice. This is a problem since my` __getattr__` itself needs to call a method, resulting in an infinite loop. Please let me know if this behavior can be reverted. 
```
import equinox as eqx

class Foo(eqx.Module):
    baz: str = "foobaz"

    def __getattr__(self, name):
        print("you've hit getattr", name)
        return "getattr"

    def moo(self):
        return "moo"

print(Foo().baz)  # existing variable
print(Foo().pie)  # missing variable
print(Foo().moo())  # existing method
```
Output:
```
foobaz
you've hit getattr pie
getattr
you've hit getattr __name__
you've hit getattr __qualname__
moo
```
