### Reproduction

In my use case of accelerate, I want to use multiprocessing. However, loading a model with `model = AutoModelForCausalLM.from_pretrained("gpt2", device_map={"": "cuda"})` raises an error, while loading with

```python
with torch.device("cuda"):
    model = AutoModelForCausalLM.from_pretrained("gpt2")
```

goes fine. See the full example below.

```python
from transformers import AutoModelForCausalLM
import torch
import multiprocessing as mp

class ValidationProcess(mp.Process):
    def __init__(self, model):
        super().__init__()
        self.model = model

    def run(self):
        print("hehehe")

if __name__ == "__main__":
    mp.set_start_method("spawn")

    """
    with torch.device("cuda"):
        model = AutoModelForCausalLM.from_pretrained("gpt2")
    """

    model = AutoModelForCausalLM.from_pretrained("gpt2", device_map={"": "cuda"})

    p = ValidationProcess(model)
    p.start()
    p.join()
```
