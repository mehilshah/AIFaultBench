# recovered-from-issue: https://github.com/jax-ml/jax/issues/38101

TITLE
`jax.jit + jax.vmap composition`: jit(vmap(f))(x) != vmap(f)(x) for `relu → square → sqrt_abs` at float32.max

BODY
### Description


JIT-compiling a vmapped function suppresses `inf` that arises in eager vmap. For the program `relu → square → sqrt_abs`, squaring `float32.max` overflows to `inf` in eager mode, which propagates through `sqrt_abs` to give `inf`. JIT clips the overflow back to `float32.max` instead.

Minimal reproducer:

```python
import numpy as np
import jax, jax.numpy as jnp

def program(x):
    return jnp.sqrt(jnp.abs(jnp.square(jax.nn.relu(x))))  # relu → square → sqrt_abs

x = jnp.array([3.4028235e+38], dtype=jnp.float32)  # float32.max

jit_result   = np.asarray(jax.jit(jax.vmap(program))(x))
eager_result = np.asarray(jax.vmap(program)(x))

print("jit(vmap(f))(x):", jit_result)   # [3.4028235e+38]
print("    vmap(f)(x): ", eager_result) # [inf]
assert np.allclose(jit_result, eager_result, rtol=1e-5, atol=1e-5)  # AssertionError
```

Expected output:
```
jit(vmap(f))(x): [inf]
    vmap(f)(x):  [inf]
```

Actual output:
```
jit(vmap(f))(x): [3.4028235e+38]
    vmap(f)(x):  [inf]
```
