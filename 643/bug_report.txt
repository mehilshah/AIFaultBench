# recovered-from-issue: https://github.com/pyro-ppl/pyro/issues/2724

TITLE
contrib.funsor.infer.TraceEnum_ELBO can compute inaccurate elbo for certain guide-enumerated models 

BODY
### Issue Description
Calculating marginal `logq` in the guide (`log_prob` in `contrib.funsor.infer.TraceEnum_ELBO`) for some cost terms can lead to inaccurate elbo values. E.g., in the test below for the cost term `log p(c|b)` computing marginal of `logq(a)q(b|a)` integrates out `a` which shouldn't be done because `q(b|a)` plated factors are conditionally independent only given `a`.

### Environment
 - Pyro `dev` branch and Funsor `master` branch

### Code Snippet
Command:
`pytest tests/contrib/funsor/test_enum_funsor.py::test_elbo_enumerate_plate_9`

    @infer.config_enumerate
    def guide_plate():

    @infer.config_enumerate

    elbo = infer.TraceEnum_ELBO(max_plate_nesting=0)
