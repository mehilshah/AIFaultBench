TITLE
Graclus hangs indefinitely on GPU

BODY
### 🐛 Describe the bug

I'm trying to set up a GCN with graclus pooling, but the Graclus function hangs indefinitely when I run a forward pass through the GPU. It works fine on the CPU.

Specs & Reproduction:
- PyTorch: 2.4.1+cu124
- NVIDIA RTX 4070 
- [batch_edge_index.txt](https://github.com/user-attachments/files/24023432/batch_edge_index.txt)
- [batch_edge_attr.txt](https://github.com/user-attachments/files/24023433/batch_edge_attr.txt)
```
import numpy as np
import torch
import torch.nn as nn

from torch_geometric.nn import GCNConv, graclus

class Debug(nn.Module):
    def forward(self, edge_index, edge_weight):
        clusters = graclus(edge_index, edge_weight)
        return True

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = Debug().to(device)
edge_index = torch.tensor(np.loadtxt("batch_edge_index.txt"), dtype=torch.long).to(device)
edge_attr = torch.tensor(np.loadtxt("batch_edge_attr.txt"), dtype=torch.float).to(device)

out = model(edge_index, edge_attr)
print(f"Graclus exited with GPU: {out}")
```

I've stepped through things and it seems to freeze on the call to torch.ops.torch_cluster.graclus, which I think is the CUDA implementation. Any help would would be appreciated. 🙂
