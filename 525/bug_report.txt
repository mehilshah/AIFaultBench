TITLE
[BUG] Potential issue with torchvision ImageNet in `create_dataset`?

BODY
**Describe the bug**
When trying to use the torchvision `ImageNet` class via `create_dataset`, a [`download` argument is created internally](https://github.com/huggingface/pytorch-image-models/blob/main/timm/data/dataset_factory.py#L116) and [passed to the class constructor](https://github.com/huggingface/pytorch-image-models/blob/main/timm/data/dataset_factory.py#L150) even though it's not expecting an argument with that name (see [1](https://github.com/pytorch/vision/blob/main/torchvision/datasets/imagenet.py#L52), [2](https://github.com/pytorch/vision/blob/main/torchvision/datasets/folder.py#L319)).

**To Reproduce**
Steps to reproduce the behavior:
1. run `dataset_train = create_dataset('torch/imagenet', root=PATH_TO_YOUR_IMAGENET_ROOT)`

**Expected behavior**
A working dataset class to be created
