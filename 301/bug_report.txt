# recovered-from-issue: https://github.com/Lightning-AI/pytorch-lightning/issues/21778

TITLE
FSDPStrategy  fails on CPU with  RuntimeError: FSDP needs a non-CPU accelerator device  when validation is bypassed

BODY
### Bug description                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                           
While PyTorch Lightning currently blocks FSDP on CPU at the `Trainer`/`Fabric` level with a `ValueError` ("The strategy `fsdp` requires a GPU accelerator"), the underlying `FSDPStrategy` itself is broken on CPU when this check is bypassed (e.g.,  
  during unit testing or when using custom strategy subclasses).                                                                                                                                                                                           
                                                                                                                                                                                                                                                           When running `FSDPStrategy` on CPU, it attempts to initialize PyTorch's `FullyShardedDataParallel` with `device_id=self.root_device.index`. Since `root_device.index` is `None` for CPU, it passes `device_id=None`.                                   
                                                                                                                                                                                                                                                           
In PyTorch 2.5+, passing `device_id=None` on a CPU-only setup triggers a guard in PyTorch that expects a non-CPU accelerator, leading to a `RuntimeError`. To support FSDP on CPU (e.g., for testing), `FSDPStrategy` must explicitly pass the CPU     
  device object (`torch.device('cpu')`) instead of `None`.                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                           
### What version are you seeing the problem on?                                                                                                                                                                                                        
                                                                                                                                                                                                                                                           
    v2.5, v2.6                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                           
### How to reproduce the bug                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                           
    ```python                                                                                                                                                                                                                                              
    import os                                                                                                                                                                                                                                              
    import torch                                                                                                                                                                                                                                           
    import torch.nn as nn                                                                                                                                                                                                                                  
    import torch.distributed as dist                                                                                                                                                                                                                       
    from lightning.pytorch.strategies import FSDPStrategy                                                                                                                                                                                                  
                                                                                                                                                                                                                                                           
    if __name__ == "__main__":                                                                                                                                                                                                                             
        # Initialize a basic distributed environment (required by FSDP)                                                                                                                                                                                    
        os.environ["MASTER_ADDR"] = "localhost"                                                                                                                                                                                                            
        os.environ["MASTER_PORT"] = "29500"                                                                                                                                                                                                                
        dist.init_process_group("gloo", rank=0, world_size=1)                                                                                                                                                                                              
                                                                                                                                                                                                                                                           
        strategy = FSDPStrategy()                                                                                                                                                                                                                          
        strategy._parallel_devices = [torch.device("cpu")]                                                                                                                                                                                                 
                                                                                                                                                                                                                                                           
        # Mock LightningModule wrapper                                                                                                                                                                                                                     
        class MockLightningModule(nn.Module):                                                                                                                                                                                                              
            def __init__(self):                                                                                                                                                                                                                            
                super().__init__()                                                                                                                                                                                                                         
                self.layer = nn.Linear(2, 2)                                                                                                                                                                                                               
                self.trainer = None                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                           
        strategy._lightning_module = MockLightningModule()                                                                                                                                                                                                 
                                                                                                                                                                                                                                                           
        model = nn.Linear(2, 2)                                                                                                                                                                                                                            
        
        # This will trigger the PyTorch FSDP error
        strategy._setup_model(model)

### Suggested Fix
  
In both Fabric and PyTorch FSDP strategies, conditionally set  device_id  based on the device type:
  
    device_id = self.root_device if self.root_device.type == "cpu" else self.root_device.index
  
This needs to be applied in:
  
  •  src/lightning/fabric/strategies/fsdp.py 
  •  src/lightning/pytorch/strategies/fsdp.py
