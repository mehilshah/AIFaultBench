Title: projections_from_fundamental output shape is different than advertised
Date: 2021-05-03T08:54:13+00:00
URL: https://github.com/kornia/kornia/issues/997

Description:
## 🐛 Bug

The [docs](https://kornia.readthedocs.io/en/v0.5.0/geometry.epipolar.html#kornia.geometry.epipolar.projections_from_fundamental) state that the output shape is `(*, 4, 4, 2)` where in reality it's `(*, 3, 4, 2)` (which is reasonable, given that most other APIs assume projection matrices are 3x4, but still). In other words, I consider it a doc bug rather than code bug.

Additionally, I find it non-intuitive that the dimension relating to the two matrices (P1 and P2) is the last dimension, rather than the leading (aside from batch) dimension. Prior to consulting the docs, based on kornia conventions, I'd expect the output to be `(*, 2, 3, 4)`, but perhaps rectifying this is too much of a breaking change to be worth it.

## To Reproduce

```python
import torch
import kornia

F = torch.randn(1, 3, 3)
print(kornia.projections_from_fundamental(F).shape) # prints `(1, 3, 4, 2)`.
```

## Expected behavior

Output of shape `(*, 4, 4, 2)` or an update to the docs.
