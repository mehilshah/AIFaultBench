# recovered-from-issue: https://github.com/pyro-ppl/numpyro/issues/2161

TITLE
Tracer leaks during NUTS sampling on random_nnx_module when NNX module contains mutable state

BODY
### Bug Description

The current implementation of `numpyro.contrib.module.random_nnx_module` leaks tracers during MCMC sampling via NUTS if the transformed NNX module contains mutable state. 

I found that in some situations, like in the example below, an exception is only raised when (1) JAX's leak checking is enabled, or (2) `numpyro.deterministic` is used. Other setups, for example when using `nnx.BatchNorm` (the norm doesn't need to be applied, it is enough to add it to the NNX module), raise an error regardless of (1) and (2).

The leaked tracers appear to mainly originate from the `stop_gradient` call and/or the assignment to `mutable_holder` in these lines of `nnx_module`:
https://github.com/pyro-ppl/numpyro/blob/0fcf1218c27e7f562cc1f1bae8d9d3c1f9c7d52e/numpyro/contrib/module.py#L371-L374

Commenting out line 373 *or* 374 apparently fixes the issue.

For more information, see the reproduction example and the output below.

### Steps to Reproduce

I first noticed this issue using JAX 0.8.1 and NumPyro 0.19.0 when experimenting with a model containing `nnx.BatchNorm`, but the most recent versions (JAX 0.9.2, NumPyro 0.20.1) run into the same issue as well. The newer versions even behave more consistently, with leaks also occurring when only using a single `nnx.Variable`. This did not happen in the older JAX version.

The following script should reproduce the issue and showcase the different cases described above using JAX 0.9.2 and NumPyro 0.20.1:
```py
from functools import partial

import jax
import numpyro
from flax import nnx
from numpyro.contrib.module import random_nnx_module


class NNXModel(nnx.Module):
    def __init__(self, use_mutable: bool) -> None:
        self.linear = nnx.Linear(10, 1, rngs=nnx.Rngs(0))
        self.mutable = nnx.Variable(0) if use_mutable else None

    def __call__(self, x: jax.Array) -> jax.Array:
        return self.linear(x)


def model_fn(model: nnx.Module, x: jax.Array, y: jax.Array | None = None, use_deterministic: bool = False) -> jax.Array:
    random_model = random_nnx_module("model", model, numpyro.distributions.Normal(0, 1))

    x = random_model(x)

    with numpyro.plate("plate", size=x.shape[0]):
        x = numpyro.deterministic("x", x) if use_deterministic else x
        return numpyro.sample("obs", numpyro.distributions.Normal(x, 1.0).to_event(1), obs=y)


x = jax.random.uniform(jax.random.key(0), shape=(10, 10))
y = jax.random.uniform(jax.random.key(0), shape=(10, 1))

print("Run MCMC without mutable state...")
try:
    mcmc = numpyro.infer.MCMC(
        numpyro.infer.NUTS(partial(model_fn, NNXModel(use_mutable=False))),
        num_warmup=10,
        num_samples=10,
    )
    with jax.check_tracer_leaks(True):
        mcmc.run(jax.random.key(0), x, y)
except Exception as e:
    print("Error! Message: \n\n", e)
print()

print("Run MCMC with mutable state (without deterministic)...")
try:
    mcmc = numpyro.infer.MCMC(
        numpyro.infer.NUTS(partial(model_fn, NNXModel(use_mutable=True))),
        num_warmup=10,
        num_samples=10,
    )
    mcmc.run(jax.random.key(0), x, y)
except Exception as e:
    print("Error! Message: \n\n", e)
print()

print("Run MCMC with mutable state (without deterministic, trace checker enabled)...")
try:
    mcmc = numpyro.infer.MCMC(
        numpyro.infer.NUTS(partial(model_fn, NNXModel(use_mutable=True))),
        num_warmup=10,
        num_samples=10,
    )
    with jax.check_tracer_leaks(True):
        mcmc.run(jax.random.key(0), x, y)
except Exception as e:
    print("Error! Message: \n\n", e)
print()

print("Run MCMC with mutable state (with deterministic)...")
try:
    mcmc = numpyro.infer.MCMC(
        numpyro.infer.NUTS(partial(model_fn, NNXModel(use_mutable=True), use_deterministic=True)),
        num_warmup=10,
        num_samples=10,
    )
    mcmc.run(jax.random.key(0), x, y)
except Exception as e:
    print("Error! Message: \n\n", e)
print()

print("Run MCMC with mutable state (with deterministic, trace checker enabled)...")
try:
    mcmc = numpyro.infer.MCMC(
        numpyro.infer.NUTS(partial(model_fn, NNXModel(use_mutable=True), use_deterministic=True)),
        num_warmup=10,
        num_samples=10,
    )
    with jax.check_tracer_leaks(True):
        mcmc.run(jax.random.key(0), x, y)
except Exception as e:
    print("Error! Message: \n\n", e)
print()
```
