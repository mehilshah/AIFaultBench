Title: Python SDK for Katib and Kubeflow Pipelines can not be installed at the same time
Date: 2024-06-08T17:53:52+00:00
URL: https://github.com/kubeflow/katib/issues/2346

Description:
### What happened?

Currently, If you try install the latest versions of the `kfp` and `kubeflow-katib` libraries at the same time, there is a dependency version conflict.

This is caused by a number of conflicts:

1. [`kfp==2.7.0` needs `protobuf>=4.21.1,<5`](https://github.com/kubeflow/pipelines/blob/sdk-2.7.0/sdk/python/requirements.in#L21) but [`kubeflow-katib` needs `protobuf>=3.19.5,<=3.20.3`](https://github.com/kubeflow/katib/blob/v0.17.0-rc.0/sdk/python/v1beta1/setup.py#L26)
2. [`kfp==2.7.0` needs `kubernetes>=8.0.0,<27`](https://github.com/kubeflow/pipelines/blob/sdk-2.7.0/sdk/python/requirements.in#L20) but [`kubeflow-katib` needs `kubernetes>=27.2.0`](https://github.com/kubeflow/katib/blob/v0.17.0-rc.0/sdk/python/v1beta1/setup.py#L24)

See for yourself by trying the following command:

```shell
pip install kfp==2.7.0 kubeflow-katib==0.17.0rc0
```

### What did you expect to happen?

The latest versions of both `kfp` and `kubeflow-katib` can be installed at the same time.
