# recovered-from-issue: https://github.com/jax-ml/jax/issues/38097

TITLE
`jax.jit + jax.grad + jnp.log + jnp.exp`: jit(grad(sum(log(exp(x))))) != eager grad — XLA identity rewrite hides exp overflow in gradient

BODY
### Description


XLA rewrites `log(exp(x))` to `x` (identity) before differentiation, so `jit(grad(...))` returns `1.0` everywhere. In eager mode, when `exp(x)` overflows to `inf` (at x ≥ 88.72 for float32), the gradient is `nan`; when underflow occurs, the gradient is `0.0`. Two distinct failures were found.

Minimal reproducer:

```python
import numpy as np
import jax, jax.numpy as jnp

# Case 1: exp(89) overflows → eager grad is nan, jit grad is 1.0
x1 = jnp.array([89.0], dtype=jnp.float32)
jit1   = np.asarray(jax.jit(jax.grad(lambda x: jnp.sum(jnp.log(jnp.exp(x)))))(x1))
eager1 = np.asarray(jax.grad(lambda x: jnp.sum(jnp.log(jnp.exp(x))))(x1))
print("x=89  jit:", jit1, " eager:", eager1)  # [1.] vs [nan]

# Case 2: exp(88) overflows → eager grad is 0.0, jit grad is 1.0
x2 = jnp.array([88.0], dtype=jnp.float32)
jit2   = np.asarray(jax.jit(jax.grad(lambda x: jnp.sum(jnp.log(jnp.exp(x)))))(x2))
eager2 = np.asarray(jax.grad(lambda x: jnp.sum(jnp.log(jnp.exp(x))))(x2))
print("x=88  jit:", jit2, " eager:", eager2)  # [1.] vs [0.]
```

Expected output:
```
x=89  jit: [nan]  eager: [nan]
x=88  jit: [0.]   eager: [0.]
```

Actual output:
```
x=89  jit: [1.]   eager: [nan]
x=88  jit: [1.]   eager: [0.]
```
