### Description

### Description

`MultiQueryRetriever.unique_union()` crashes with `TypeError: unhashable type: 'list'` when documents have list or dict values in metadata

### File

`libs/langchain/langchain/retrievers/multi_query.py:151`

```python
unique_documents_dict = {
    (doc.page_content, tuple(sorted(doc.metadata.items()))): doc
    for doc in documents
}

Reproduction

from langchain_core.documents import Document

docs = [
    Document(page_content="hello", metadata={"tags": ["python", "ai"], "source": "web"}),
    Document(page_content="world", metadata={"tags": ["data"], "source": "db"}),
]

# Simulate unique_union:
unique = {
    (doc.page_content, tuple(sorted(doc.metadata.items()))): doc
    for doc in docs
}
# TypeError: unhashable type: 'list'

Also crashes with nested dict metadata:
docs = [Document(page_content="test", metadata={"source": {"type": "api", "url": "http://..."}})]
# TypeError: unhashable type: 'dict'

Suggested fix

Use json.dumps(doc.metadata, sort_keys=True, default=str) for hashing instead of tuple(sorted(items())).
