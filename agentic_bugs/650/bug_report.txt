TITLE
BUG: `GradioUI(...).launch()` does not work because of deprecated keyword argument to `gr.Blocks`

BODY

**Problem**
`GradioUI(agent).launch()` does not work. This is because `gr.Blocks` no longer accepts `theme` as an argument. [This is the line](https://github.com/huggingface/smolagents/blob/2ae00fb092d1b0e7d74de06e738dd48d04a8b2c2/src/smolagents/gradio_ui.py#L419) where the keyword `theme` is passed, and [this is the place](https://github.com/gradio-app/gradio/blob/28b49e3e74fc73dff938a2b7f53325d554fdf680/gradio/blocks.py#L1016) in gradio where you see that this argument is no longer accepted.

**Steps to reproduce**
This is the way to reproduce _only_ the offending line in `gradio_ui.py`.
```python
import gradio as gr
gr.Blocks(theme="ocean", fill_height=True)
```

**Actual behavior and error logs**
While trying to define an agent using `GradioUI(agent).launch()`, the following error was seen:
```shell

    super().__init__(render=False, **kwargs)

```

**Expected behavior**
Expected the GradioUI app to be launched.
