# recovered-from-issue: https://github.com/langflow-ai/langflow/issues/12228

TITLE
Module Not Found Errors running langflow-ide - missing required litellm module's

BODY
### Bug Description

Missing packages as the `extra` packages required by litellm are not installed as not specified in `pyproject.toml`

https://github.com/langflow-ai/langflow/blob/cacb54d6013d04851e7217f9a9f224f8ba7eaaa7/src/backend/base/pyproject.toml#L280

Update to:
`litellm = ["litellm[proxy]>=1.60.2,<2.0.0"]`

This will add the packages specified here: https://github.com/BerriAI/litellm/blob/b4a5e516680bb23e48e876cadbd3a76b3bacc100/pyproject.toml#L82-L108

Without, when running langflow-ide it throws errors when logging, note multiple packages are required (e.g. apscheduler, fastapi-sso, ...) - see different error messages below after having resolved the first missing package locally.

### Reproduction

langflow-ide running in kubernetes Azure AKS cluster, v.1.32.10. Connected to `litellm` as an openai endpoint and logging to `langfuse`

See example two errors below, the first after install, the second after manually adding the `apscheduler` package:
