# recovered-from-issue: https://github.com/SWE-agent/SWE-agent/issues/1179

TITLE
swe-bench Docker image uses Python 3.5, incompatible with `tree-sitter==0.21.3` required by edit_anthropic

BODY
### Describe the bug

Hi team,

I’m encountering an issue when trying to install the `edit_anthropic` tool as part of running **SWE-agent-v1.1.0**. Specifically, the base swe-bench Docker image appears to use **Python** `3.5.6`, which is too old to support `tree-sitter==0.21.3` (requires **Python** `>=3.8`). This causes installation failures when setting up the environment.

### Steps/commands/code to Reproduce

```bash

#!/bin/bash

set -e

EVAL_SWEAGENT_VERSION="1.1.0"

INSTANCE_ID="django__django-7530"
OUTPUT_DIR="outputs/$INSTANCE_ID"
DATASET="princeton-nlp/SWE-bench_Verified"
SUBSET="verified"

CUSTOM_LLM_PROVIDER="litellm_proxy"
BASE_URL="http://127.0.0.1:8000/v1"
API_KEY="token-abc123"
MODEL="claude-3-7-sonnet-20250219"
TEMPERATURE="0.0"

# clean up output directory if it exists
rm -rf $OUTPUT_DIR

# run inference
/root/miniconda3/envs/swe-agent-v$EVAL_SWEAGENT_VERSION/bin/sweagent run-batch \
    --output_dir $OUTPUT_DIR \
    --instances.filter=$INSTANCE_ID \
    --instances.type=swe_bench \
    --instances.subset=$SUBSET \
    --instances.split=test \
    --instances.shuffle=False \
    --instances.evaluate=False \
    --instances.deployment.startup_timeout=600 \
    --agent.model.name=$CUSTOM_LLM_PROVIDER/$MODEL \
    --agent.model.api_base=$BASE_URL \
    --agent.model.api_key=$API_KEY \
    --agent.model.temperature=$TEMPERATURE \
    --agent.model.per_instance_call_limit="150" \
    --agent.model.retry.retries=30 \
    --agent.tools.parse_function.type="function_calling" \
    --config config/benchmarks/250225_anthropic_filemap_simple_review.yaml

```
