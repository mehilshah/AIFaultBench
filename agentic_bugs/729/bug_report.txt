# recovered-from-issue: https://github.com/microsoft/semantic-kernel/issues/13298

TITLE
Python: Bug: Fix import path: microsoft.agents vs microsoft_agents

BODY
**Describe the bug**
ImportError when trying to use CopilotStudioAgent. The semantic-kernel library imports from `microsoft.agents.copilotstudio.client` (with dots) but the actual package name is `microsoft_agents` (with underscores), causing an import failure.

The problematic import statement in the code is:
```python
from microsoft.agents.copilotstudio.client import AgentType
```

But it should be:
```python
from microsoft_agents.copilotstudio.client import AgentType
```

**To Reproduce**
Steps to reproduce the behavior:
1. Install semantic-kernel: `pip install semantic-kernel`
2. Install the required dependencies: `pip install --extra-index-url https://test.pypi.org/simple microsoft-agents-core microsoft-agents-copilotstudio-client`
3. Try to import CopilotStudioAgent: `from semantic_kernel.agents import CopilotStudioAgent`
4. See ImportError: `ModuleNotFoundError: No module named 'microsoft'` or similar error

**Expected behavior**
The import should succeed and CopilotStudioAgent should be available for use as described in the official documentation.
