**Steps to reproduce**
Example from the docs here `https://huggingface.co/docs/smolagents/tutorials/secure_code_execution`, plus checking explicitly for E2B variables: 

```python
from dotenv import load_dotenv
import os
from smolagents import CodeAgent, LiteLLMModel
# read environment variables in
load_dotenv()
# make sure the var is in
assert 'E2B_API_KEY' in os.environ, "E2B_API_KEY not found in environment variables"
assert os.environ['E2B_API_KEY'], "E2B_API_KEY is empty"
# simple model
model = LiteLLMModel(
        model_id="gpt-4o-mini",
        api_key=os.getenv("OPENAI_API_KEY")
    )
with CodeAgent(add_base_tools=False, tools=[], model=model, executor_type="e2b") as agent:
    result = agent.run("Calculate the sum of numbers from 1 to 10")
    print(result)
```
