TITLE
Bug: ...sensitive_data parameter

BODY
### Browser Use Version

0.11.1-0.11.5

### Bug Description, Steps to Reproduce, Screenshots

when used sensitive_data with task agent is inputting literal placeholder user_name,pass_word instead of actual value given

### Failing Python Code

```python
import asyncio
from browser_use import Agent, ChatGoogle,ChatOpenAI
from dotenv import load_dotenv
import os
os.environ['ANONYMIZED_TELEMETRY'] = "false"
load_dotenv()
GEMINI_API_KEY = ""

sensitive_data_new = {
    'user_name': 'learner@gmail.com',
    'pass_word': 'learner'
}
task='''
1. Log into https://applications.webomates.com/elearning/ put the secure information in the relevant fields with username user_name and password pass_word and ROLE-learner and generate javaseleniumtestng  code for automation for steps performed
'''
from browser_use import Agent, Browser
browser = Browser(wait_between_actions=2.0)  # 1 second wait


agent = Agent(
    task=task,
    sensitive_data=sensitive_data_new,
    browser=browser,
    save_conversation_path="./130/conversations",
    # available_file_paths=['./browser_use_data/results.md'],
    extended_system_prompt="always use exact placeholder value from sensitive_data.",
    use_vision=False,
    llm=ChatGoogle(model='gemini-2.5-flash', api_key="")
)

async def main():
    await agent.run()

asyncio.run(main())
```
