TITLE
UnicodeEncodeError in Python Logging: Handling Emojis with cp1252 Encoding Issue

BODY
I'm encountering a `UnicodeEncodeError` when logging messages containing emojis. The error occurs when attempting to encode characters like `\U0001f916` (🤖) using the `cp1252` encoding, which doesn't support these characters. This happens in the logging system while writing to the output stream.

I've tested this with both OpenAI and OpenRouter models, but the issue persists. It seems to be related to how Python's logging module interacts with the system's encoding settings.

To resolve this, I set the encoding to UTF-8 and ran the following command:

```
chcp 65001
set PYTHONIOENCODING=utf-8
python -m sweagent run --config=config/openrouter.yaml
```

However, I'm still encountering the same error.

Has anyone else experienced this? Possible solutions might involve forcing UTF-8 encoding globally or modifying the logging handler.
