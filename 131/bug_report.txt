Title: [Bug]: TextRegressor breaks due to unrelated labels
Date: 2024-07-03T23:34:03+00:00
URL: https://github.com/flairNLP/flair/issues/3489

Description:
### Describe the bug

`TextRegressor._labels_to_tensor` iterates over every label on the sentence; not just the regression label specified by `self.label_name`. This leads to unexpected behavior. 

For example, TextRegressor cannot be used as part of a multitask model. `_labels_to_tensor` will attempt to convert the `multitask_id` into a float, which throws an error. More generally, the TextRegressor will encounter an error any time there is more than one label on a sentence.

### To Reproduce

```python
from flair.models import TextRegressor
from flair.data import Sentence, Corpus
from flair.embeddings import TransformerEmbeddings
from flair.trainers import ModelTrainer

sentences = [Sentence("This is a sentence") for _ in range(100)]
for sentence in sentences:
    sentence.add_label("regression_label", 4.5)
    sentence.add_label("foo", "bar") # Unrelated label breaks the TextRegressor

corpus = Corpus(sentences)
regressor = TextRegressor(TransformerEmbeddings('bert-base-uncased'), label_name="regression_label")
trainer = ModelTrainer(regressor, corpus)
trainer.train('regression_model/')
```


### Expected behavior

When I set the `label_name` parameter on a TextRegressor, I expect the model to train on said label, and ignore the rest. I also expect TextRegressor to work with multitask training.
