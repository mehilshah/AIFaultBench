Title: eqx.field with default value causing TypeError
Date: 2026-01-26T13:47:29+00:00
URL: https://github.com/patrick-kidger/equinox/issues/1172

Description:
Hi, I seem to have run into an odd bug. When setting a default value through `eqx.field` in an `eqx.Module`, and using this module in the carry of a `lax.scan` **ánd** applying `vmap` to this carried module causes `TypeError: can only concatenate str (not "_Sentinel") to str`. 

Below is a minimal example.

```python
import equinox as eqx
import jax
import jax.numpy as jnp


class SomeNetwork(eqx.Module):
    layer: eqx.nn.Linear
    some_eqx_field_value: int = eqx.field(default=42, static=True)

    def __init__(self, key):
        self.layer = eqx.nn.Linear(3, 5, key=key)

    def __call__(self, x):
        return self.layer(x)


key = jax.random.PRNGKey(0)
critic = SomeNetwork(key)
batch = jnp.zeros((1, 2, 3))


def scan_fn(carry, x):
    # vmap on carry inside a scan triggers the error
    out = jax.vmap(carry)(x)
    return carry, out


try:
    jax.lax.scan(scan_fn, critic, batch)
    print("All good")
except Exception:
    print("Error")
    import traceback

    traceback.print_exc()

```

Tested in version 0.13.3. Problem does not exist <= 0.13.2
