# recovered-from-issue: https://github.com/jax-ml/jax/issues/38098

TITLE
`jax.jit + jax.grad + jnp.log2 + jnp.exp2`: jit(grad(sum(log2(exp2(x))))) != eager grad — XLA identity rewrite changes gradient at overflow boundary

BODY
### Description


XLA rewrites `log2(exp2(x))` to `x` (identity) before differentiation. This makes `jit(grad(...))` return `1.0` everywhere, while eager mode returns the correct chain-rule gradient (`0.0`) when `exp2(x)` is at the overflow boundary in float32.

Minimal reproducer:

```python
import numpy as np
import jax, jax.numpy as jnp

x = jnp.array([126.0], dtype=jnp.float32)

jit_result   = np.asarray(jax.jit(jax.grad(lambda x: jnp.sum(jnp.log2(jnp.exp2(x)))))(x))
eager_result = np.asarray(jax.grad(lambda x: jnp.sum(jnp.log2(jnp.exp2(x))))(x))

print("jit(grad(sum(log2(exp2(x))))):", jit_result)   # array([1.], dtype=float32)
print("    grad(sum(log2(exp2(x)))): ", eager_result)  # array([0.], dtype=float32)
assert np.array_equal(jit_result, eager_result)  # AssertionError
```

Expected output:
```
jit(grad(sum(log2(exp2(x))))): [0.]
    grad(sum(log2(exp2(x)))):  [0.]
```

Actual output:
```
jit(grad(sum(log2(exp2(x))))): [1.]
    grad(sum(log2(exp2(x)))):  [0.]
```
