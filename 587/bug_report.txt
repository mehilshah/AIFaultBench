## Minimal reproducible code

```python
from openai import OpenAI
from pydantic import BaseModel

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")
MODEL = "Qwen/Qwen3.6-27B"
PROMPT = ("A bat and a ball cost $1.10 in total. The bat costs $1.00 more than the ball. "
          "How much does the ball cost? Answer with just the dollar amount.")

class Answer(BaseModel):            # answer-only schema
    answer: str
class ReasonedAnswer(BaseModel):    # reasoning field BEFORE answer
    reasoning: str
    answer: str

msgs = [{"role": "user", "content": PROMPT}]

# (1) free-form
r = client.chat.completions.create(model=MODEL, messages=msgs, temperature=0.0, max_tokens=2048)
c = r.choices[0].message.content or ""
print("(1) free-form          tokens:", r.usage.completion_tokens, "has <think>:", "</think>" in c)

# (2) structured, answer-only schema
r = client.beta.chat.completions.parse(model=MODEL, messages=msgs, response_format=Answer, temperature=0.0, max_tokens=2048)
c = r.choices[0].message.content or ""
print("(2) structured {answer} tokens:", r.usage.completion_tokens, "has <think>:", "</think>" in c, "raw:", repr(c))

# (3) structured, reasoning field first
r = client.beta.chat.completions.parse(model=MODEL, messages=msgs, response_format=ReasonedAnswer, temperature=0.0, max_tokens=2048)
print("(3) structured {reasoning,answer} tokens:", r.usage.completion_tokens,
      "| reasoning present:", bool(r.choices[0].message.parsed.reasoning))
```

## Observed output

```
=== (1) free-form (no response_format) ===
completion_tokens: 1152 | has <think>: True
content[:400]: 'Here\'s a thinking process:\n\n1.  **Analyze the User Input:** ...'

=== (2) structured response_format=Answer{answer} ===
completion_tokens: 16 | has <think>: False
parsed: answer='0.05' | raw content: '{\n  "answer":  "0.05"\n}'

=== (3) structured response_format=ReasonedAnswer{reasoning,answer} ===
completion_tokens: 130
parsed.reasoning[:300]: 'Let the cost of the ball be x. Then the cost of the bat is x + 1.00 ...'
parsed.answer: '0.05'
```

## Expected vs actual

- **Expected:** with thinking-on as the chat-template default, a `response_format` request would still emit the `<think>…</think>` chain before the constrained JSON (as it does for free-form), then produce the schema-valid output.
- **Actual:** the constrained request skips thinking entirely (case 2: 16 tokens, no `<think>`), unless the schema itself contains a leading field for the reasoning to occupy (case 3).
