TITLE
[BUG] MinariExperienceReplay fails with remote datasets

BODY
## Describe the bug

Minari.load_dataset line fails if the dataset is downloaded by TorchRL, thus saved in TorchRL's cache, instead of the default Minari path.

Thus, MinariExperienceReplay fails:
https://github.com/pytorch/rl/blob/74abd6c38c065a17aeaa4bd617167055e434fdad/torchrl/data/datasets/minari_data.py#L473

## To Reproduce

Simply launch:
```python
import torchrl

ds = MinariExperienceReplay("D4RL/door/human-v2", batch_size=32)
```
